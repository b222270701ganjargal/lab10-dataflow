## Хэсэг B — bonus() функцийн өгөгдлийн урсгал

### B2. Хувьсагчдын Definition ба Use

| Хувьсагч | Definition мөр | c-use мөр | p-use мөр |
|---|---|---|---|
| attendance | 31 | 38 | 32 |
| threshold | 31 | Байхгүй | 32, 50 |
| a | 38 | Байхгүй | 39 |
| present | 35, 40 | 40 | 50 |
| streak | 36, 41, 46 | 41, 43 | 42 |
| best | 37, 43 | Байхгүй | 42, 53 |
| score | 49, 51, 54 | 54, 56 | Байхгүй |

**Definition (def):** Хувьсагчид утга оноох үйлдэл.

**c-use:** Тооцоолол, утга оноолтын баруун тал,
буцаах илэрхийлэлд хувьсагч ашиглах.

**p-use:** Нөхцөл шалгах илэрхийлэлд хувьсагч
ашиглах.

**Kill буюу дахин тодорхойлолт:**
- 40-р мөр: present-ийн өмнөх утгыг шинэчилнэ.
- 41-р мөр: streak-ийн өмнөх утгыг шинэчилнэ.
- 43-р мөр: best-ийн өмнөх утгыг шинэчилнэ.
- 46-р мөр: streak-ийг 0 болгож дахин тодорхойлно.
- 51-р мөр: score-ийн өмнөх утгыг 5 болгоно.
- 54-р мөр: score-д 3 нэмж дахин тодорхойлно.

32-р мөрийн || оператор short-circuit үнэлгээтэй.
attendance == null үед threshold < 0 нөхцөл
шалгагдахгүй.

38-р мөрийн for-each давталт attendance массивын
элементүүдийг уншиж, давталт бүрд a хувьсагчид
шинэ утга онооно.

### B3. Kill болон def-clear замын шинжилгээ

| Хувьсагч | Анхны Definition | Kill хийх мөр | Тайлбар |
|---|---|---|---|
| present | 35 | 40 | Ирсэн өдрийн тоог нэмэгдүүлнэ |
| streak | 36 | 41, 46 | Дараалсан ирэлтийг нэмэх эсвэл 0 болгоно |
| best | 37 | 43 | Хамгийн урт дарааллыг шинэчилнэ |
| a | 38 | 38 (дараагийн давталт) | Дараагийн элементийн утгыг авна |
| score | 49 | 51, 54 | Оноог 5 болгох эсвэл 3 нэмэх |
| score | 51 | 54 | Өмнөх оноог нэмэгдүүлнэ |

**Def-clear зам:** Хувьсагчийн definition-оос use
хүртэл тухайн хувьсагчид дахин утга оноогоогүй зам.

Жишээ:

- present: 35 → 38 → 39(T) → 40
  Анхны present=0 утга 40-р мөрөнд ашиглагдана.
- streak: 36 → 38 → 39(T) → 41
  Анхны streak=0 утга 41-р мөрөнд ашиглагдана.
- best: 37 → 38 → 39(T) → 40 → 41 → 42
  Анхны best=0 утга нөхцөлд ашиглагдана.
- score: 49 → 50(F) → 53(F) → 56
  score=0 өөрчлөгдөхгүйгээр буцна.

**Биелэх боломжгүй DU хосын жишээ:**

- streak-ийн 36 → 42 хос боломжгүй.
  Учир нь 42-р мөрийн нөхцөлд хүрэхээс өмнө
  41-р мөр streak-ийг заавал дахин тодорхойлно.

- score-ийн 49 → 56 хос нь 51 эсвэл 54-р мөр
  ажилласан замд def-clear биш.
  Харин хоёр оноолтыг алгассан замд боломжтой.

Kill болсон definition-оос use хүртэлх замыг
def-clear хос гэж тооцохгүй.

  нөхцөл заавал True болно.

  best >= 5 нөхцөл True болох боломжгүй.
  True болохын тулд 43-р мөрөнд best
  дахин тодорхойлогдсон байх шаардлагатай.

- B1: bonus(null, 0) — IllegalArgumentException

- B8: bonus(new int[]{1, 1, 1, 1, 1}, 5) → 8

32-р мөрийн нөхцөлийн short-circuit шинжилгээ:

- B1: attendance == null → True.
  threshold < 0 нөхцөл шалгагдахгүй.
- B2: attendance == null → False,
  threshold < 0 → True.
- B3: attendance == null → False,
  threshold < 0 → False.

DU хүснэгтийн attendance 31→32(T/F) нь эхний
нөхцөл, threshold 31→32(T/F) нь хоёр дахь
нөхцөлийн үр дүнг илэрхийлнэ.
32-р мөрийн хоёр нөхцөлийг short-circuit зарчмаар тусад нь авч үзсэн.
